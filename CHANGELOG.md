# Changelog

## 1.0.0-beta.1 - 2026-08-30

- Added the first public Dedicated Dungeons framework beta for Minecraft 1.21.1 and NeoForge.
- Added isolated U-API dungeon instances, procedural room assembly, party deployment, persistence, recovery and transactional cleanup.
- Added datapack-driven dungeon definitions, level profiles, rooms, connectors, mob and boss pools, loot profiles and reward pools.
- Added dungeon keys, automatic and operator-created portals, Survival Arena, portal pressure and rank-aware encounter scaling.
- Added English and Russian localization, authoring marker blocks, validation commands and guarded optional mod content.
- Bundled Forgotten Depths as a small vanilla test dungeon generated from internal fixture rooms. It is demonstration content, not a handcrafted production dungeon.
- Added tag-driven publication to GitHub Releases, Modrinth and optionally CurseForge with U-API declared as required.
